# жука / jooka.net
Интерактивный дизайн-прототип. jooka.net — желаемое имя, домен не подключён.
Статика в dist/. Запуск: python3 server.py (отдаёт dist/ и автосохраняет данные в data/jooka-data.json, копия за каждый день в data/history/).
Коллекции, поиск, единое окно добавления, редактирование, перемещение и вложения до 50 МБ.
Тексты в localStorage, файлы в IndexedDB. Данные привязаны к браузеру и адресу; это не резервная копия и не синхронизация.
Образцы помечены «пример», не содержат пользовательских файлов. Запись лекции работает (микрофон, пауза, аудио во вложении). AI и расшифровка пока не подключены.
Дизайн: белый #ffffff, нейтральный фон #f7f7f9, текст #202022, вторичный #94949a, акценты коллекций #b9c6eb/#e1cdea/#cdd6bd. Системная типографика Mac. Одна выразительная деталь — стопки обложек; спокойный рабочий интерфейс.

Копии: заметки (папка data/) автоматически уходят в ветку main приватного репозитория liromweb/jooka_web, код приложения после каждого коммита в ветку app того же репозитория.
